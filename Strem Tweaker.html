Historique versions

Résumé très court des changements depuis la v1.6b.

V2.1.0
Nouveau : logo/mascotte à côté du titre "Strem Tweaker" (chat mécano en illustration, fond transparent).
V2.0.16
Correction : en cas d'échec du chargement des addons juste après une connexion (AuthKey invalide, erreur ponctuelle...), l'interface restait bloquée sur un écran vide (panel de connexion ET panel addons masqués). Le formulaire de connexion se réaffiche désormais automatiquement pour permettre de réessayer.
V2.0.15
Nouveau dans Config appli : "État de la mémoire (bibliothèque Stremio)" — nombre total d'éléments dans ta bibliothèque, et taille en Ko des 2 entrées propres à l'app (config + points de sauvegarde), pour surveiller si elles approchent une limite de taille côté API.
V2.0.14
Les points de sauvegarde sont désormais synchronisés via ton compte Stremio (multi-appareils) au lieu du localStorage, dans une entrée de librairie dédiée et séparée de la config principale — pour ne jamais risquer de casser la synchro des addons supprimés/verrouillés si les sauvegardes grossissent. Limité aux 5 plus récentes. Migration automatique et transparente des points déjà créés localement.
V2.0.13
Corrections points de sauvegarde : le titre n'est plus barré (réutilisait par erreur le style des addons supprimés) ; la restauration ne crée plus de sauvegarde automatique fantôme à 0 addon quand la liste actuelle est déjà vide.
V2.0.12
Nouveau : section "Où sont stockées mes données ?" dans Paramètres (légende expliquant l'emplacement de chaque réglage : localStorage vs bibliothèque Stremio). Nouveau : Points de sauvegarde (icône dans la toolbar addons) — snapshots nommés créés à la demande, stockés dans ce navigateur, restaurables en un clic (avec sauvegarde automatique de l'état courant avant restauration).
V2.0.11
La position d'un addon verrouillé est désormais protégée de façon absolue : plus aucun autre addon ne peut prendre sa place, même en glissant un autre addon par-dessus (avant, la position pouvait décaler d'un cran par effet de bord). Un addon qui tente de "passer devant" un addon verrouillé est automatiquement redirigé juste avant lui, et tout ce qui se trouvait entre les deux se décale en conséquence.
V2.0.10
Le cadenas devient un bouton cliquable (vert = non verrouillé, rouge = verrouillé). Un addon verrouillé ne peut plus être supprimé ni déplacé (drag & drop, monter/descendre), mais reste éligible aux mises à jour. Pré-verrouillé automatiquement pour les addons marqués "protégés" par Stremio à la première utilisation, entièrement modifiable ensuite. Réglage synchronisé multi-appareils comme les addons supprimés.
V2.0.9
Nouveau : "Tout mettre à jour" télécharge désormais une sauvegarde JSON automatique avant d'appliquer les mises à jour (même filet de sécurité que la RAZ complète des addons). Une mise à jour peut changer le comportement d'un addon sans avertissement — ce backup permet de revenir en arrière via "Restaurer (JSON)".
V2.0.8
Nouveau : icône de cadenas à côté de chaque addon indiquant s'il est marqué "protégé" par Stremio (flags.protected, ex. Cinemeta). Cadenas fermé = protégé, ouvert = non protégé. La suppression d'un addon protégé affiche désormais un avertissement explicite avant confirmation.
V2.0.7
Nouveau : détection des addons injoignables (badge "⚠ Hors ligne", via le bouton "Vérifier les mises à jour") et des doublons (même ID d'addon installé plusieurs fois, badge "⧉ Doublon", détecté automatiquement). Détection uniquement — aucune suppression automatique.
V2.0.6
Correction visuelle : le bouton "Annuler" de la modal d'édition utilisait la classe ghost, jamais stylée — il se confondait visuellement avec les boutons standards. Ajout d'un style transparent/discret pour bien le distinguer du bouton "Sauvegarder" (primary).
V2.0.5
Correction visuelle : les modals Addons supprimés, Infos utilisateur et Config appli utilisaient la classe CSS modal-box, jamais stylée (fond, bordure, padding et coins arrondis absents). Remplacée par modal-card, comme les autres modals.
V2.0.4
Nettoyage : le formulaire de connexion (panel principal + modal Paramètres) partage désormais une seule fonction de câblage (bindLoginForm) au lieu de deux copies dupliquées. Aucun changement fonctionnel.
V2.0.3
Nettoyage : suppression du code mort (renderAppConfig, exportLibraryConfig, razLibraryConfig, remplacés depuis V4.7 par renderAppConfigTables/exportRemoteConfig/razRemoteConfig) et des déclarations dupliquées de openDeletedModal/closeDeletedModal/openAppConfigModal/closeAppConfigModal. Aucun changement fonctionnel.
V2.0.2
Sécurité : correction de deux failles XSS stockées (échappement HTML manquant) dans les modals Config appli (dump JSON de deletedAddons) et Infos utilisateur (champs de profil Stremio : nom, email, langue, ID, avatar).
V2.0.1
Historique visionnage : suppression du filtre removed:true — de nombreux films visionnés ont ce flag dans Stremio sans avoir été supprimés. Seuls la config (CONFIG_ID) et les items supprimés dans la session courante sont exclus.
V2.0.0
Refonte majeure. Synthèse de toutes les versions V1.7 → V5.9 :

Gestion des addons — réorganisation par drag & drop, activation/désactivation, suppression avec corbeille (restauration possible), RAZ complète avec sauvegarde auto, installation par URL avec choix de position (premier/dernier), vérification et application des mises à jour unitaires et groupées (Tout mettre à jour), sauvegarde/restauration JSON.

Historique de visionnage — liste groupée par date locale, filtres Films/Séries, heure de visionnage, badge dernier épisode (séries), suppression individuelle, RAZ complète, import/export JSON, recherche.

Config librairie Stremio — stockage de loginCollapsed et deletedAddons dans un libraryItem dédié (strem-tweaker-config) pour synchronisation multi-appareils. Encodage dans le champ name (champs non-standard strippés par Stremio). Auto-résurrection si removed:true.

Infos utilisateur — popup avec avatar, nom, email, date d'inscription, statut premium, langue.

Config appli — tableau localStorage vs config librairie, export localStorage, RAZ localStorage, export/RAZ config librairie, export librairie complète.

UI — menu utilisateur avec Infos utilisateur / Config appli / Paramètres / Historique versions / Déconnexion. Icône historique visionnage dans le hero. Toolbar addons centrée avec séparateur. Compteur addons dans le titre. Modal addons supprimés avec badge. Boutons historique compacts sur mobile.
